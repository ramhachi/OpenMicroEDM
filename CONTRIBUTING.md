# Contributing

This project is in feasibility validation. Contributions that reduce uncertainty are more valuable than feature expansion.

Preferred contribution order:

1. reproduce/measure an existing subsystem;
2. identify a failure mode;
3. add instrumentation or a falsifiable experiment;
4. only then add complexity.

For mechanical/electrical changes, include:

- design intent;
- what requirement/failure mode it addresses;
- assumptions;
- measurement or calculation supporting the change;
- links to relevant prior art/datasheets/papers;
- safety impact.

Do not present simulated resolution, microstep size, CAD precision, or nominal screw pitch as measured machine accuracy.
