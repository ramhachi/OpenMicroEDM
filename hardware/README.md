# Hardware

Mechanical hardware lives here.

Planned modules:

- `fine_z/` — first printed flexure axis and electrode carrier.
- `fine_xy/` — tool-side XY flexure for milling (Phase 2).
- `spindle/` — low-runout micro-electrode spindle/coupling.
- `fluid/` — bath, recirculation, filtration, flushing fixtures.
- `macro_stage/` — deferred until local EDM is stable.
- `metrology/` — fixtures for external displacement measurement and camera/fiducials.

Design rule: keep CAD parameterized and separate experimentally measured dimensions/properties from nominal model values.
