# Experiments

Use one directory per experiment, for example:

```text
experiments/
  E000_fine_stage_repeatability/
    README.md
    config.yaml
    raw/
    processed/
    analysis/
```

Before collecting data, write:

- question;
- hypothesis;
- setup;
- independent/dependent variables;
- stop conditions;
- expected failure modes;
- analysis method.

Afterward, add raw data unchanged and record deviations from the preregistered procedure.

Suggested first experiment IDs are defined in [`../docs/validation-plan.md`](../docs/validation-plan.md).
