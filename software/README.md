# Software

Host-side tooling is expected to cover:

- experiment configuration and metadata capture;
- waveform logging and plotting;
- stage calibration/error-map generation;
- tool-wear tracking;
- local fiducial registration;
- EDM drilling and later milling toolpath generation;
- tile/stitch planning for the macro/micro machine.

Reproducibility rule: every plotted result should be regenerable from committed code plus an identified raw-data file.
