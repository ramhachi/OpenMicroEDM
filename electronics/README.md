# Electronics

Planned blocks:

1. **Pulse-power stage** — intentionally energy/current limited; electrically separated from logic.
2. **Gap-voltage sensing** — isolated or safely referenced acquisition with known bandwidth.
3. **Gap-current sensing** — sufficient bandwidth to classify discharge events.
4. **Motion I/O** — fine Z / XY actuator drive.
5. **Interlocks** — enclosure, fluid, emergency stop, overcurrent/fault handling.

The first deliverable is not a high-performance pulse generator. It is a safely instrumented, conservative source that permits waveform capture and controlled short-circuit experiments.

Do not commit a schematic as "validated" until measured waveforms and protection behavior are recorded in `experiments/`.
